Design scheme · v0.1 · for review

Quiet confidence for a serious job search.

Resumate should feel like a senior recruiter’s desk, not a consumer job board. Warm paper, precise ink, one decisive green, and gold reserved for match. Professional, credible, modern — never loud.

Light-first Editorial serif + UI sans Forest · Paper · Gold Dark mode supported

Principles

These constrain every later screen. If a component fights them, the component loses.

Trust before delight

People upload a résumé. The UI should look like it can keep a secret and give an honest score — no neon, no mascots, no purple SaaS default.

One accent, used sparingly

Forest is the brand and the action color. Gold is only for match quality. Terracotta is rare: tailor / caution. Everything else stays paper and ink.

Readable like a document

Headlines can be literary. Body copy and job data stay crisp and slightly tight. Scores, keywords, and file names live in mono.

Color

Warm ivory instead of sterile gray. Forest instead of LinkedIn blue. Gold instead of traffic-light green for the thing that matters most: fit.

UI language

14px radius, hairline borders, a soft paper shadow. Buttons are slightly squared — confident, not bubbly.

Radius & space

Do / don’t

Do

Warm paper canvas. Forest buttons. Gold only on the score. Serif for titles. Honest language: “tailor,” not “hack the ATS.” High contrast text. One primary action per screen.

Don’t

Inter + violet gradients. Cool zinc backgrounds. Rainbow skill chips. Fake 99% matches. Comic illustrations. Rounded-pill everything. Gold as body text (contrast fails).
